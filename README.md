# parcial
3 pantallas 
Pantalla 1 (Perfil y Clanes): Muestra el perfil del usuario, lista de juegos populares y clanes disponibles para unirse.

Pantalla 2 (Vista del Clan): Detalle del clan seleccionado, lista de miembros y control de estado para llamadas de voz (Focus/Blur).

Pantalla 3 (Asignaciones):Registro de misiones del clan y contador de interacciones.
